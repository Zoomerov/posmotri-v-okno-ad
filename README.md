# Посмотри в окно

Учебный репозиторий проектной работы по HTML и CSS Яндекс Практикума.

## Структура

- `index.html` — разметка страницы и шаблоны карточек, загрузки и ошибок.
- `styles/style.css` — основные стили страницы.
- `styles/preloader.css` — индикатор загрузки.
- `styles/error.css` — оформление сообщений об ошибках.
- `scripts/script.js` — загрузка видео, поиск и переключение карточек.
- `fonts/` — локальные шрифты.

## Запуск

Запустите `python -m http.server 8000` из корня проекта и откройте http://localhost:8000.
Для получения видео требуется доступ к внешнему API.
